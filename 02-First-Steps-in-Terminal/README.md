# First Steps in the Terminal

## Overview

This section introduces the Linux terminal and the essential commands used to navigate and interact with the operating system. It covers basic command-line usage, directory navigation, command chaining, and accessing Linux documentation.

---

## Skills Practised

- Outputting text with `echo`
- Using `echo -n` and `echo -e`
- Displaying the current directory with `pwd`
- Navigating directories using `cd`
- Moving to parent directories (`cd ..`, `cd ../..`)
- Listing directory contents with `ls`
- Using common `ls` options:
  - `ls -a`
  - `ls -r`
  - `ls -t`
- Understanding absolute and relative paths
- Executing multiple commands with `;`
- Accessing command documentation using `man` and `--help`
