# Linux-Labs

This repository documents my Linux learning journey through hands-on labs, shell scripting projects, networking exercises, and system administration practice.

---

## Project Goal

The goal of this repository is to build practical Linux administration skills through hands-on labs, scripting projects, networking exercises, and real-world system administration tasks.

By the end of this project, I aim to confidently administer Linux systems, automate tasks using Bash, manage servers, troubleshoot issues, and build a strong foundation for networking, cybersecurity, and DevOps.

---


## Topics Covered

- Linux Fundamentals
- Linux Command Line (CLI)
- File & Directory Management
- Text Processing
- Users, Groups & Permissions
- Process & Job Management
- Package Management (APT & DNF)
- Storage, Partitions & LVM
- Networking & SSH
- Web Server Deployment
- System Administration
- SELinux
- Bash Scripting
- Shell Automation
- APIs & JSON
- Regular Expressions (grep)
